# MotoManutenção 🏍️

Sistema de controle de manutenção para motoboys.

## Funcionalidades
- ✅ Controle de veículos
- ✅ Registro de serviços
- ✅ Estatísticas de custos
- ✅ Alertas de manutenção
- ✅ PWA (Instalável)

## Tecnologias
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Deploy: Render.com
